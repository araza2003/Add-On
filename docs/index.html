Ship big Odoo modules to GitHub, without the upload limit

A small app that runs on your computer. Pick a folder or drop a zip, choose a repository and branch, and push. Built for Odoo.sh teams whose modules are too big for drag and drop.

How it works

1. Add your GitHub token

Your username is detected for you. Save as many tokens as you like, one per account or client.

2. Pick your modules

Browse to a folder or drop a .zip. Add-On scans it, counts your Odoo modules and warns about files GitHub would reject.

3. Push

Choose the repository and branch, then watch each step run. No merge conflicts, because it clones first.

Install on Ubuntu

sudo apt install -y git rsync zenity python3
git clone https://github.com/araza2003/Add-On.git
cd Add-On
python3 odoo-pusher.py

Your tokens stay in a file on your own computer that only you can read. Pushes go straight from your machine to GitHub.
